# F1 Dashboard

A hobby project built with the [jolpica-f1](https://github.com/jolpica/jolpica-f1) -
where users can explore the latest race results, lap times, and event details.
View upcoming or past races, check current driver and constructor standings, and explore detailed driver profiles — all in one place.

---

## ✨ Features
- View upcoming and past races
- See race results and lap times
- View detailed driver info and statistics 
- Check driver standings
- Check constructor standings

---

## 🧠 Tech Stack
- **React**  
- **TypeScript**  
- **jolpica-f1**  
- **Tailwind CSS**  
- **Vite**
- **Vercel**
